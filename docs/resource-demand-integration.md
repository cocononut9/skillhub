# 资源与需求功能整合

集成分支：`integration/resource-and-demand`。

本分支包含插件上传及安装包扫描、Markdown 提示词资源、Codex 使用统计、需求广场。README 展示信息和网站资源功能继承自本地 `main`。需求广场仍只提供发布、支持和场景补充。

## 分支来源

- `feat/demand-square` 基于 `feat/codex-skill-usage`，需求广场先保存为独立提交。
- `feat/prompt-resource-upload` 已包含 `feat/plugin-resource-upload`，合并提示词分支同时纳入插件功能。
- 集成不改变各功能分支的历史，不自动合入 `main` 或推送远程。

## 数据库迁移

| 版本 | 内容 | 整合处理 |
| --- | --- | --- |
| V49 | 网站资源 | 保留 |
| V50 | 插件资源 | 保留原脚本，校验和 `1860160560` |
| V51 | 提示词资源 | 保留原脚本，校验和 `-72597489` |
| V52 | Codex 使用统计 | 从未在原开发库执行的同名 V50 脚本改号，SQL 内容不变 |
| V53 | 需求广场 | 从未在原开发库执行的同名 V51 脚本改号，SQL 内容不变 |

此前同一开发库在插件、提示词分支已执行 V50、V51；另一个分支复用了版本号，导致启动校验失败。整合后，已有插件/提示词数据库只需追加 V52、V53；不需要 `repair`、修改历史校验和或删除原库。

旧的独立使用统计/需求预览库采用另一套 V50/V51 历史，不能直接切换到本分支运行。它们应继续隔离保留；若需要迁移其中的测试数据，应另行按表迁移，不能覆盖历史校验和。

## 验证与启动

- `make test-backend-app`：包括全新 PostgreSQL 安装测试，以及 `ResourceDemandMigrationTest` 的 V51 → V53 升级、数据保留、历史校验和与重复启动验证。
- `make test-frontend`、`make lint-web`、`make typecheck-web`：验证合并后的页面和类型。
- `make generate-api`：根据整合后的后端重新生成接口类型。
- `cd web && pnpm exec playwright test e2e/demand-square.spec.ts --reporter=line`：验证需求发布、支持、补充维护和移动端显示。

本次本地整合预览使用 `skillhub_integration_preview`：只复制原开发库的表结构与迁移记录，再从仓库初始化内置角色、权限和全局空间。没有复制原账号凭据或业务内容，也没有更新原 `skillhub` 数据库。

整合版可通过 `.dev` 下的独立预览配置测试；标准 `make dev-all` 仍使用默认 `skillhub` 数据库，并会实际执行尚未应用的迁移。运行前先核对当前分支和数据库历史，避免旧分支连接已升级的共享数据库。

本地验证不等于生产部署或业务验收；正式上线前仍须执行部署回归与人工业务验收。
