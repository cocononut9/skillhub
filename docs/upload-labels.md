# 上传时选择已有标签

上传页提供可搜索、多选的普通标签列表，标签为选填项。列表沿用现有可见标签库，不提供新建入口；需要新标签时，由上传者私下联系管理员添加。

## 使用与权限

- 普通用户从已有普通标签中选择，不能通过上传接口新建标签或添加特权标签。
- 超级管理员在「标签管理」维护标签库，可新建、修改显示名称、调整类型及可见性、删除标签。内部标识 slug 保持不变。
- 超级管理员在资源详情页添加或移除挂载的普通标签、特权标签；替换标签通过移除旧标签、添加新标签完成。
- 从资源移除标签，只解除当前资源的关联；从标签库删除标签，会解除所有资源与该标签的关联并删除其翻译，不删除资源。
- 标签改名后，已挂载资源使用新的显示名称；原有搜索同步和审计记录继续生效。

## 上传行为

- 上传请求增加可选的 `labelSlugs` 参数，使用标签的稳定标识提交。没有该参数的已有客户端行为不变。
- 标签关联与上传的数据库变更在同一事务中保存。不存在的标签、无权使用的标签及超限选择会报错。
- 上传新版本仅追加所选标签，保留全部原标签，包括管理员挂载的特权标签；不选标签也不会清空原标签。
- 选中已挂载的标签不会重复创建关联，包括已达到数量上限时。
- 沿用 `skillhub.label.max-per-skill`，默认每个资源最多 10 个标签；不新增数据库结构或标签审核流程。

## 验证

```bash
make test-backend-app
make test-frontend
make typecheck-web lint-web
```

主要回归包括：上传与挂载、管理员改名与替换挂载标签、普通用户权限、更新保留标签、数量上限与数据库回滚，以及执行现有 V34 迁移后的级联删除。

`PublishLabelsIntegrationTest` 还验证上传 OpenAPI 参数。可通过 Maven 系统属性 `skillhub.openapi.output` 导出测试环境中的接口定义，供隔离环境生成前端类型，避免使用其他分支正在运行的后端。
